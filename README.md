# Hecke

Research workspace on Hecke algebras H(G,H) = End_G(C[G/H]), focusing on non-Gelfand pairs arising from cubic arc-transitive graphs. Includes LaTeX papers, a catalog of Hecke algebras computed in GAP, explicit irreducible representations, and collaboration materials with Nick Meinhold.

- `hecke.tex/.pdf` — main paper: Hecke algebras from scratch via double cosets and orbital graphs
- `hecke-catalog.tex/.pdf` — catalog of H(G,H) for small arc-transitive graphs
- `hecke-irreps.tex/.pdf` — explicit irreps of non-Gelfand Hecke algebras
- `why13.tex/.pdf` — the Sp(6,2) case: 13 orbital classes and Fano geometry
- `from-knots-to-hecke.tex/.pdf` — expository: knot theory to Hecke algebras
- `*.g` — GAP scripts computing structure constants, irreps, and census data
- `MEINHOLD-HECKE.md`, `meinhold_*.g` — collaboration workspace with Nick
